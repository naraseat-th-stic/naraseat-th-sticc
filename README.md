# ระบบติดตามงาน (Job & Ticket Tracker)
### สำหรับ: นายนราเศรษฐ์ ธัญศิรอนันต์

ระบบติดตามงานที่ออกแบบมาเป็นพิเศษ เน้นความ **"เรียบง่าย เข้าใจง่าย ไม่ซับซ้อน เหมาะสำหรับผู้ที่ไม่มีความรู้ด้าน IT"** โดยสามารถเปิดใช้งานได้ทันทีบนคอมพิวเตอร์ผ่านเว็บเบราว์เซอร์ (Google Chrome, Microsoft Edge ฯลฯ) ไม่ต้องติดตั้งโปรแกรมหรือเซิร์ฟเวอร์ใดๆ

---

## 🚀 วิธีการเปิดใช้งาน (คลิกเดียวใช้งานได้ทันที)
1. ดับเบิลคลิกที่ไฟล์ **`เปิดระบบติดตามงาน-นายนราเศรษฐ์.bat`** หรือ **`Start-MyJob.bat`** บนไดรฟ์ `D:\`
2. หรือเข้าไปที่โฟลเดอร์ `D:\MyJob\` แล้วดับเบิลคลิกที่ **`index.html`** หรือ **`เปิดโปรแกรม.bat`**
3. ระบบจะเปิดขึ้นมาบนหน้าต่างเบราว์เซอร์พร้อมใช้งานได้ทันที!

---

## 🌟 ฟังก์ชันหลักตามความต้องการ

### 1. ➕ สร้างใบงานใหม่ (Create Ticket)
- **หัวข้องาน:** ระบุชื่องานที่ต้องทำ
- **รายละเอียดงาน:** บันทึกสิ่งที่ต้องทำเพิ่มเติม
- **วันเริ่มงาน และ วันสิ้นสุดงาน:** มีปฏิทินให้เลือกวัน/เดือน/ปี
- **ระยะเวลาการมอบหมายงาน:** ระบบคำนวณจำนวนวันให้อัตโนมัติ (เช่น 3 วัน, 5 วัน)
- **ผู้มอบหมายงาน:** สามารถพิมพ์ชื่อเอง หรือคลิกเลือกรายชื่อประจำได้อย่างรวดเร็ว (เช่น คุณสมศักดิ์, ฝ่ายจัดซื้อ, ฝ่ายบัญชี ฯลฯ)
- **ระดับความสำคัญ:** แบ่งเป็น 4 ระดับสีชัดเจน
  - 🔴 ด่วนที่สุด (Highest)
  - 🟠 ด่วน (High)
  - 🟡 ปานกลาง / ปกติ (Normal)
  - 🟢 ทั่วไป / ต่ำ (Low)
- **หมวดหมู่งาน:** เอกสารและสัญญา, ตรวจนับสต็อก, ประสานงาน ฯลฯ

### 2. 📅 ติดตามงานรายสัปดาห์ (Weekly Tracker)
- **ตารางงานประจำสัปดาห์:** แสดงปฏิทิน 7 วัน (จันทร์ - อาทิตย์) พร้อมระบุว่าวันไหนมีกำหนดส่งงานใดบ้าง
- **งานประจำวันนี้ (Today's Priorities):** รวบรวมงานที่ต้องทำในวันนี้ไว้ด้านบนสุดเพื่อให้เห็นชัดเจนทันทีที่เปิดระบบ
- **ปุ่มเลื่อนสัปดาห์:** สลับดู "สัปดาห์ก่อนหน้า", "สัปดาห์นี้" และ "สัปดาห์ถัดไป" ได้ง่ายดาย

### 3. 🚨 ระบบแจ้งเตือนงานล่าช้าอัตโนมัติ (Overdue Alerts)
- **ล่าช้าเกิน 3 วัน:** ขึ้นแถบเตือนสีส้ม `⚠️ แจ้งเตือน: มีงานล่าช้าเกินกำหนด 3 วัน`
- **ล่าช้าเกิน 5 วันขึ้นไป:** ขึ้นแถบเตือนสีแดงกระพริบ `🚨 แจ้งเตือนเร่งด่วน: มีงานล่าช้าเกินกำหนดมากกว่า 5 วัน!`
- มีปุ่มลัดบนแถบเตือนเพื่อคลิกกรองดูเฉพาะงานที่ค้างและต้องรีบส่งทันที

### 4. 🏆 ผลงานที่เสร็จสมบูรณ์ (Completed Works Archive)
- **แยกประเภทตามรายปีและรายเดือน:**
  - ตัวกรองปี พ.ศ. (เช่น 2569, 2568 หรือทุกปี)
  - ตัวกรองเดือน (มกราคม - ธันวาคม หรือทุกเดือน)
  - ตัวกรองหมวดหมู่งาน
- **สถิติความสำเร็จ (KPI):** สรุปยอดงานที่เสร็จในงวด, อัตราส่งมอบงานตรงเวลา (%), หมวดหมู่งานหลัก, ผู้มอบหมายงานหลัก
- **กราฟแท่งแสดงผลงาน 12 เดือน:** แท่งกราฟสวยงามแสดงจำนวนงานที่ทำเสร็จในแต่ละเดือน คลิกที่แท่งเดือนเพื่อกรองดูงานเดือนนั้นได้ทันที
- **พิมพ์รายงานผลงาน (Print Performance Report):** จัดหน้ากระดาษเป็นรายงานทางการเพื่อเสนอผู้บริหาร
- **ส่งออก Excel เฉพาะงานที่เสร็จ:** นำไปทำรายงาน KPI หรือรายงานประจำปีได้ทันที

### 5. 📊 เชื่อมต่อ Google Sheets เป็น Cloud Database (ข้อมูลอยู่ตลอดเวลา)
- สามารถเชื่อมต่อกับ **Google Sheets** เพื่อใช้เป็นฐานข้อมูลบนคลาวด์ถาวร
- เมื่อเชื่อมต่อแล้ว ทุกครั้งที่มีการสร้างใบงาน, แก้ไข, หรือเปลี่ยนสถานะงาน ระบบจะซิงค์ข้อมูลขึ้น Google Sheets โดยอัตโนมัติ
- ป้องกันข้อมูลสูญหาย เปิดดูข้อมูลงานจากสมาร์ทโฟนหรือคอมพิวเตอร์เครื่องอื่นผ่าน Google Sheets ได้ทุกเวลา
- มีคู่มือแนะนำการเชื่อมต่อแบบเข้าใจง่ายใน 3 นาที พร้อมปุ่มกดคัดลอกโค้ดไปวางได้ทันทีในแท็บ "คลาวด์ & สำรองข้อมูล"
- หากยังไม่ได้เชื่อมต่อ Google Sheets ระบบจะยังคงบันทึกข้อมูลในเครื่อง (LocalStorage) ให้อัตโนมัติอย่างปลอดภัย

### 6. 📋 ฟังก์ชันเสริมอื่นๆ ที่เป็นประโยชน์
- **📊 หน้าแรกสรุปภาพรวม (Dashboard):** แสดงการ์ดตัวเลขสรุปงานทั้งหมด, งานที่กำลังทำ, งานเสร็จแล้ว, งานล่าช้า
- **📌 กระดานงาน (Kanban Board):** แยกเสาคอลัมน์ รอดำเนินการ, กำลังดำเนินการ, เสร็จสมบูรณ์ ให้เห็นกระบวนการทำงานชัดเจน
- **🖨️ พิมพ์ใบงานเดี่ยว (Print / PDF):** คลิกเปิดใบงานแล้วกดปุ่ม "พิมพ์ใบงาน" เพื่อพิมพ์เป็นเอกสาร A4 สำหรับแนบแฟ้มหรือเสนอลายเซ็นได้ทันที
- **📗 ส่งออกข้อมูลเป็น Excel (CSV):** รองรับภาษาไทย 100% ไม่เป็นภาษาต่างดาว
- **💾 สำรองและกู้คืนข้อมูล (Backup & Restore):** เซฟไฟล์เก็บไว้ หรือกู้คืนข้อมูลได้ง่ายดาย
- **🔄 ข้อมูลตัวอย่าง (Demo Data):** มีระบบโหลดข้อมูลตัวอย่างสำหรับทดลองเล่น และปุ่มล้างข้อมูลเมื่อต้องการเริ่มใช้งานจริง
